## Notas

- El enlace "directo" usa `Special:FilePath`, una redirección estable de Wikimedia Commons que apunta al archivo de imagen real; se puede usar tal cual en cualquier documento o navegador.
- Se agregó `?width=200` para obtener una miniatura pequeña; se puede cambiar el valor (o quitar el parámetro) para obtener otras resoluciones o el original.
- Estas imágenes son **referenciales por tipo de producto** (una imagen genérica de "procesador", "placa madre", etc.), no fotos de los modelos/SKU exactos listados en el archivo original (ej. no es una foto específica del "PROC AMD RYZEN 5 8500G"). Si necesitas fotos del modelo/SKU exacto de cada producto, se requeriría una búsqueda individual por producto (~166 productos).
