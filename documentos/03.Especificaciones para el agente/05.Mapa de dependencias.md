# 📊 Mapa de Dependencias de Documentos

| Etapa      | Documento                             | Contenido                                  | Uso / Dependencia                                                 |
| ---------- | ------------------------------------- | ------------------------------------------ | ----------------------------------------------------------------- |
| **Diseño** | Especificación Técnica del PC Builder | Flujo en cascada, reglas de compatibilidad | Define las reglas de negocio que guían el modelado y validaciones |
| **Diseño** | Arquitectura del Sistema              | Diagrama de módulos, roles, flujo de datos | Base para estructurar frontend, backend y base de datos           |
| **Diseño** | Documento de API                      | Endpoints, request/response, validaciones  | Guía para implementar servicios backend con Prisma                |

| **Desarrollo** | Listado de Productos y Características | Inventario real con atributos técnicos | Fuente de datos inicial para poblar la BD | | **Desarrollo** | Modelo de Base de Datos (schema.prisma) | Tablas: Producto, Atributo, Cliente, Cotización | Define estructura de BD en Neon/PostgreSQL | | **Desarrollo** | Script de Seed (prisma/seed.ts) | Carga inicial de productos y atributos | Dependiente del listado de productos | | **Desarrollo** | Documento de UX/UI | Mockups, pantallas, mensajes de error | Guía para construir interfaz en Next.js |

| **Pruebas** | Checklist de Pruebas Funcionales | Casos CPU → PSU, cotizaciones | Validación manual de compatibilidad | | **Pruebas** | Documento de Pruebas Automatizadas | Casos unitarios e integración | Scripts de testing con Jest/Playwright | | **Pruebas** | Documento de Migraciones y Seed | Estrategia de carga y actualización | Asegura consistencia de datos en pruebas |

| **Despliegue** | Documento de Seguridad y Autenticación | Roles, permisos, login | Control de acceso en producción | | **Despliegue** | Documento de Despliegue | Configuración `.env`, deploy en Vercel/Neon | Guía para publicar y mantener el sistema |

## 🔑 Lectura del Mapa

- **Diseño**: se apoya en la **especificación técnica** y la **arquitectura** para definir reglas y estructura.
    
- **Desarrollo**: depende del **listado de productos** y el **schema Prisma** para implementar base de datos y lógica.
    
- **Pruebas**: usan el **checklist** y los **scripts automatizados** para validar compatibilidad y cotizaciones.
    
- **Despliegue**: requiere documentos de **seguridad** y **deploy** para asegurar operación estable en producción.
