# 📘 Guía de Implementación – Proyecto CRM + Configurador de PCs

## 1. Contexto del Proyecto

- Proyecto final del curso Fullstack.
    
- Frontend: **Next.js** usando la plantilla [NextAdmin](https://nextjstemplates.com/templates/nextadmin?utm_source=copilot.com "nextjstemplates.com").
    
- Base de datos: **Neon (PostgreSQL)**.
    
- ORM: **Prisma**.
    
- Objetivo: Construir un **CRM con módulo de Configurador de PCs (PC Builder)** que permita cotizar equipos garantizando compatibilidad técnica.
    

## 2. Requisitos Técnicos

- **Frontend**: Next.js + TailwindCSS (ya incluido en la plantilla).
    
- **Backend**: API Routes de Next.js con Prisma.
    
- **Base de datos**: PostgreSQL en Neon.
    
- **ORM**: Prisma con migraciones.
    
- **Cotizaciones**: Generación de PDF y envío por WhatsApp/Correo.
    
- **Validaciones**: Compatibilidad en cascada según atributos de productos.
    

## 3. Modelado de Base de Datos (Prisma)

prisma

```
model Producto {
  id             Int                @id @default(autoincrement())
  nombre         String
  marca          String
  precioVenta    Float
  categoria      String
  subcategoria   String
  atributos      ProductoAtributo[]
  cotizaciones   CotizacionDetalle[]
  createdAt      DateTime @default(now())
  updatedAt      DateTime @updatedAt
}

model ProductoAtributo {
  id         Int      @id @default(autoincrement())
  producto   Producto @relation(fields: [productoId], references: [id])
  productoId Int
  clave      String   // ej: socket, tipoMemoria, tdp
  valor      String   // ej: AM5, DDR5, 65
  createdAt  DateTime @default(now())
}

model Cliente {
  id          Int          @id @default(autoincrement())
  nombre      String
  correo      String
  telefono    String?
  cotizaciones Cotizacion[]
  createdAt   DateTime @default(now())
}

model Cotizacion {
  id          Int                 @id @default(autoincrement())
  cliente     Cliente             @relation(fields: [clienteId], references: [id])
  clienteId   Int
  fecha       DateTime            @default(now())
  total       Float
  estado      String
  detalles    CotizacionDetalle[]
  createdAt   DateTime @default(now())
}

model CotizacionDetalle {
  id           Int       @id @default(autoincrement())
  cotizacion   Cotizacion @relation(fields: [cotizacionId], references: [id])
  cotizacionId Int
  producto     Producto   @relation(fields: [productoId], references: [id])
  productoId   Int
  cantidad     Int        @default(1)
  precioUnitario Float
  createdAt    DateTime @default(now())
}
```

## 4. Flujo del Configurador (Frontend + Backend)

1. **Paso 1 – CPU**
    
    - Selección de procesador.
        
    - Define socket, tipoMemoria, TDP, requiereCooler.
        
2. **Paso 2 – Placa Madre**
    
    - Filtrar por socket y tipoMemoria.
        
3. **Paso 3 – RAM**
    
    - Filtrar por tipoMemoria y slots disponibles.
        
4. **Paso 4 – GPU**
    
    - Validar largo físico y consumo recomendado.
        
5. **Paso 5 – Cooler**
    
    - Obligatorio si CPU requiereCooler = true.
        
    - Validar socket y TDP soportado.
        
6. **Paso 6 – Case**
    
    - Validar factor de forma, largo GPU y ventiladores.
        
7. **Paso 7 – PSU**
    
    - Validar potencia acumulada.
        
    - Obligatoria si el case no incluye fuente.
