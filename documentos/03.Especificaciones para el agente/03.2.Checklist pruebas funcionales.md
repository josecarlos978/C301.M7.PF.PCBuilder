# 📋 Checklist de Pruebas Funcionales – CRM + Configurador de PCs

|Nº|Caso de Prueba|Acción|Resultado Esperado|Estado (✔ / ✘)|
|---|---|---|---|---|
|1|CPU AM5|Seleccionar CPU AMD socket AM5|Solo se muestran placas madre AM5||
|2|CPU LGA1700|Seleccionar CPU Intel socket LGA1700|Solo se muestran placas madre LGA1700||
|3|Cooler obligatorio|Seleccionar CPU con `requiereCooler = true`|El sistema obliga a elegir cooler compatible||
|4|GPU obligatoria|Seleccionar CPU sin gráficos integrados|El sistema obliga a elegir GPU dedicada||
|5|RAM DDR5|Seleccionar placa DDR5|Solo se muestran RAM DDR5||
|6|Slots RAM|Seleccionar placa con 2 slots|Bloquea selección de más de 2 módulos RAM||
|7|RAM incompatible|Seleccionar RAM DDR4 con placa DDR5|Bloquea configuración||
|8|Frecuencia RAM|Seleccionar RAM con frecuencia superior|Permite si placa soporta frecuencia inferior||
|9|Largo GPU|Seleccionar GPU de 300mm|Solo se muestran cases con `largoMaxGpuMm >= 300`||
|10|Consumo GPU|Seleccionar GPU con consumo recomendado 650W|PSU ≥ 650W o case con fuente ≥ 650W||
|11|Cooler TDP|Seleccionar CPU con TDP 120W|Solo se muestran coolers con `tdpSoportadoWatts >= 120`||
|12|Cooler socket|Seleccionar cooler con socket incompatible|Bloquea selección||
|13|Case factor forma|Seleccionar placa ATX|Solo se muestran cases que soporten ATX||
|14|Cooler ventiladores|Seleccionar cooler con 3 ventiladores|Solo se muestran cases con `soportaFanCoolerVentiladores >= 3`||
|15|Case con fuente|Seleccionar case con fuente 250W|Bloquea GPU que requiera ≥ 300W||
|16|Case sin fuente|Seleccionar case sin fuente|El sistema obliga a elegir PSU||
|17|PSU modular|Seleccionar PSU modular/no modular|Se registra atributo correctamente, no bloquea compatibilidad||
|18|Cotización válida|Generar cotización con CPU + Placa + RAM compatibles|Calcula precio total y exporta PDF||
|19|Cotización inválida|Generar cotización con GPU incompatible|Bloquea y muestra error||
|20|Cotización WhatsApp|Enviar cotización por WhatsApp|Registra borrador en ERP||
|21|Panel admin|Modificar atributos de producto|Cambios reflejados en configurador||
|22|CRM cotizaciones|Listar cotizaciones por cliente|Permite cambiar estado (Borrador → Confirmada)||
|23|Reporte ventas|Generar reporte de ventas|Suma correctamente cotizaciones confirmadas||

## 🔑 Uso del checklist

- Cada fila corresponde a un caso de prueba.
    
- El tester debe ejecutar la acción indicada y verificar el resultado esperado.
    
- En la columna **Estado (✔ / ✘)** se marca si la prueba pasó o falló.
    
- Este checklist puede repetirse en diferentes ciclos de prueba (QA, UAT, producción).
